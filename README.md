## 这是什么？✨

IM-Board Lite是一个面向个人、项目管理者、运营团队和交付团队的聊天AI汇总看板。

它可以把分散在微信（付费功能）、企业微信、飞书、钉钉里的工作消息统一汇总，并通过AI识别：

- 谁在等你回复
- 哪些事情需要你跟进
- 哪些客户或项目出现风险
- 今天大家在讨论什么
- 哪些群最活跃
- 哪些关键词正在变热

不需要你反复切软件，也不需要手动整理聊天记录。

## Lite 版功能边界

| 平台 | Lite 版状态 | 说明 |
| --- | --- | --- |
| 企业微信 | 支持✅ | 通过 `@wecom/cli` 授权和读取 |
| 飞书 | 支持✅ | 通过 `@larksuite/cli` 授权和读取 |
| 钉钉 | 支持✅ | 通过 `@DingTalk-Real-AI/dingtalk-workspace-cli` 授权和读取 |
| 微信 | 暂不开放❌ | Lite 版界面保留入口，但功能仅限完整版本 |

想用更轻量的方式，把工作聊天变成可管理的信息流。

## 基础使用流程
1. 打开IM-Board
2. 进入平台管理
3. 按提示配置微信、企业微信、飞书或钉钉
4. 进入AI配置，选择云端AI或本地模型
5. 点击立即同步
6. 在聚合看板查看待回复、待办、风险和数据分析

## 隐私说明🔐

IM-Board Lite重视聊天数据安全。

聊天数据优先在本地处理
- 支持连接本地模型
- 可按需选择AI分析方式
- 诊断工具不会包含聊天内容、API Key等敏感数据

如果你的团队对数据安全要求较高，建议优先使用本地模型方案。

## 常见问题
### Q：需要手动导出聊天记录吗？
不需要。IM-Board Lite的目标是尽量减少手动导出和重复整理，让消息同步和分析更自动化。

### Q：支持哪些平台？
当前重点支持：
- 微信（付费功能）
- 企业微信
- 飞书
- 钉钉
具体可用能力会根据各平台本地环境和CLI支持情况有所差异。

### Q：可以不用云端AI吗？
可以。你可以选择连接本地模型，让聊天数据尽量留在本机处理。

### Q：可以自己改AI分析规则吗？
可以。你可以在AI配置里自定义提示词，让待回复、待办、热门话题和关键词云更贴合你的业务习惯。

### Q：适合完全替代人工管理吗？
不建议完全替代。IM-Board Lite更适合做信息提醒、辅助判断和风险发现，最终决策仍建议由人来确认。
