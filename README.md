# IM-Board Lite

IM-Board Lite 是一个本地优先的即时通讯聊天汇总看板，用来聚合企业微信、飞书、钉钉等工作消息，并通过 AI 分析生成待我回复、待办事项、热门话题、关键词词云和消息统计。

Lite 版聚焦工作 IM 聚合与本地看板能力。微信本机读取入口在 Lite 版中暂不开放，如需使用微信相关能力，请联系开发者了解完整版本。

## 功能特性

- 多平台账号管理：支持企业微信、飞书、钉钉账号绑定、启用/暂停、删除、批量管理和拖拽排序。
- 统一绑定流程：企业微信、飞书、钉钉通过官方 CLI 授权，绑定窗口会提供可复制的授权命令和读取测试。
- 聚合看板：支持查看全部账号聚合数据，也可以切换到单个账号看板。
- 消息同步：支持立即同步、定时同步、终止同步、重新同步和重新分析。
- AI 分析：识别待我回复、待办事项、热门话题和关键词词云，并保留消息来源上下文。
- 本地 DeepSeek：可使用应用管理的本地 DeepSeek 模型，也可以配置 OpenAI 兼容接口。
- 可视化统计：展示消息量、活跃会话、发言人排行、消息类型占比和活跃趋势。
- 诊断工具：支持导出脱敏诊断包，便于排查同步失败、授权失败、AI 返回异常和运行时问题。
- 本地数据优先：聊天数据和账号配置保存在本机，诊断包不会包含聊天内容或 API Key。

## Lite 版功能边界

| 平台 | Lite 版状态 | 说明 |
| --- | --- | --- |
| 企业微信 | 支持 | 通过 `@wecom/cli` 授权和读取 |
| 飞书 | 支持 | 通过 `@larksuite/cli` 授权和读取 |
| 钉钉 | 支持 | 通过 `@DingTalk-Real-AI/dingtalk-workspace-cli` 授权和读取 |
| 微信 | 暂不开放 | Lite 版界面保留入口，但功能仅限完整版本 |

## 技术栈

- 桌面框架：Tauri 2
- 前端：React 18、TypeScript、Vite
- 图表：Recharts
- 图标：lucide-react
- 后端：Rust、Tokio、rusqlite、reqwest
- 本地存储：SQLite
- AI 接口：本地 DeepSeek 或 OpenAI 兼容接口

## 基本使用流程

1. 打开应用，进入“账号”页面。
2. 选择企业微信、飞书或钉钉。
3. 按绑定窗口提示复制并执行授权命令。
4. 授权完成后测试读取，确认当前账号可用。
5. 回到看板，点击“立即同步”。
6. 在“AI配置”中启用本地 DeepSeek 或配置 OpenAI 兼容接口。
7. 查看待我回复、待办事项、热门话题、关键词和统计图表。

## AI 配置说明

IM-Board Lite 支持两类 AI 分析方式：

- 本地 DeepSeek：由应用管理本地模型与运行时，适合希望尽量减少外部依赖的场景。
- OpenAI 兼容接口：可配置 Base URL、模型名和 API Key，适合使用云端模型或自建推理服务。

AI 配置保存后，后续同步会按照当前提示词识别待回复、待办事项、热门话题和关键词。重新分析会清空当天 AI 结果并重新处理当天消息，但不会清除历史未完成事项。

## 数据与隐私

- 应用以本地数据为主，账号配置、同步缓存和看板数据保存在本机。
- 第三方平台消息读取依赖对应平台官方 CLI 或开源 CLI 的授权能力。
- 诊断包会进行脱敏处理，不包含聊天内容、API Key 等敏感数据。
- 不同平台的授权、接口权限和组织策略可能影响可读取范围，具体结果以平台返回为准。

## 常见问题

### 为什么 Lite 版不能绑定微信？

Lite 版暂不开放微信本机读取能力。界面中保留微信入口是为了保持产品结构一致，但该功能仅限完整版本。

### 为什么已经授权但同步不到消息？

可能原因包括平台权限不足、组织未开放消息读取能力、CLI 授权未完成、账号配置与当前授权身份不一致，或目标会话本身不允许通过接口读取。可以先在账号绑定窗口执行读取测试，再导出诊断包排查。

### 为什么 AI 看板没有待办或话题？

请先确认已经完成消息同步，并在“AI配置”中启用本地 DeepSeek 或配置可用的 OpenAI 兼容接口。如果 AI 未启用，看板会展示基础统计，但不会生成真实 AI 分析结果。

### 诊断包会泄露聊天内容吗？

不会。诊断包用于排查运行状态、授权状态、同步错误和 AI 错误，不包含聊天内容或 API Key。

## 第三方组件

IM-Board Lite 包含或调用以下第三方开源组件：

- `@wecom/cli`
- `@larksuite/cli`
- `@DingTalk-Real-AI/dingtalk-workspace-cli`
- Tauri、React、Vite、Recharts、lucide-react
- Rust 生态依赖：rusqlite、tokio、reqwest 等

完整第三方许可说明可在应用“关于软件”窗口中查看。正式发布前建议根据 `package-lock.json` 和 `Cargo.lock` 重新生成第三方许可清单，确保与实际发行包一致。
