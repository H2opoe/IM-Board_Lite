# IM-Board 更新日志

## 2.2.2

### 消息同步

- 修复微信账号当天没有新消息时可能误提示“微信读取不到消息，请确认电脑微信是否已登录”的问题。现在会正常显示已同步且读取 0 条新消息，不再误报登录异常。

## 2.2.1

### 消息同步

- 修复关闭主窗口或让应用退到后台后自动同步可能停止的问题。同步定时器改由桌面端后台任务负责，窗口隐藏后仍会按设置频率继续读取消息。

### 发布维护

- 同步 Lite macOS 版 2.2.1 发布元数据，保持应用包版本、展示版本、Tauri、Cargo、npm 和打包说明一致。

## 2.2.0

### 本地 AI

- 优化本地 DeepSeek 模型下载。大陆网络环境会优先使用 ModelScope 魔搭源，再尝试 HF-Mirror，最后回退到 Hugging Face 官方源，减少模型下载卡住或速度过慢的情况。
- 增加本地 DeepSeek 模型断点续传。网络中断或下载不完整时会保留临时文件，下次重试从已下载位置继续，避免每次都从头下载。

### 飞书同步

- 修复飞书消息检索在部分网络或代理环境下可能返回 `network/transport` 失败的问题。应用现在会为飞书官方 CLI 使用更稳定的直连环境，减少同步时出现 EOF 或传输中断的情况。
- 优化飞书官方 CLI 网络错误提示。遇到上游传输失败时，应用会提示检查网络、代理或更新 CLI，不再把整段底层 JSON 直接展示成“飞书CLI执行失败”。

## 2.1.6

### 飞书授权

- 适配新版飞书官方 CLI 授权流程。飞书绑定命令和应用内授权校验改为使用新版 `auth status`，避免旧的 `auth status --verify` 导致第二次授权后状态识别异常。
- 优化飞书授权状态识别。新版 CLI 如果把授权状态、scope 或 token 信息放在嵌套结构中，应用也能正确判断授权是否完整。
- 修复新版飞书官方 CLI 顶层 `identity: user` 与 `identities.user` 分开返回时，终端已显示“授权成功”但应用仍提示授权不完整的问题。
- 补充飞书消息检索新增的 `im:message.reactions:read` 权限，并将缺少权限的同步错误整理成补授权提示，避免在看板上直接显示大段 CLI JSON。
- 优化飞书账号身份读取。新版 CLI 如果把用户和租户信息拆到不同字段中，应用会合并识别，减少重复绑定或二次授权后读不到当前账号的问题。

## 2.1.5

### 飞书同步

- 修复飞书读测群列表可能提示“unknown flag: --as”的问题。现在应用会调用新版飞书官方 CLI 的群列表入口，并把返回结果整理成应用可识别的会话格式。
- 保留飞书同步时通过消息检索发现当天活跃会话的策略，避免群列表缺少活跃时间时扩大读取范围。
- 修复新版飞书官方 CLI 授权状态缺少旧版 `tokenStatus` 字段时被误判为未完成授权的问题；同步检索失败时也不再叠加空会话提示，减少误导。

## 2.1.4

### 账号绑定

- 修复 macOS 微信实例检测可能把企业微信也识别进去的问题。现在绑定本机微信时会更准确地区分微信和企业微信，减少选错实例的情况。
- 修复 macOS 版允许“App 管理”权限后仍可能提示无法修改微信的问题。新版安装包会使用稳定的应用身份和标准版本号，并在打包时清理旧的 macOS 配置字段后重新签名，让系统更稳定地记住 IM-Board 的授权状态。

### 消息同步

- 修复飞书同步可能一直提示“官方 CLI 执行失败”的问题。现在飞书会通过可用的消息检索方式发现今天会话，避免因为官方 CLI 不支持旧群列表命令而同步失败。

### 待回复提醒

- 优化待回复识别。对方用“请问”“能否”“可不可以”等语气提问时，即使没有标准问号，应用也会更容易识别出来，减少漏提醒。
- 优化单聊文件消息识别。对方发来报价单、报销清单、合同等文件时，应用会结合后续聊天判断是否需要你确认或回复，不再把这类消息简单当作普通文件忽略。
- 修复未完成的待回复和待办跨天后显示时间可能变化的问题。现在会尽量保留事项最初出现时的时间，避免第二天查看时日期或时间来回跳动。

### AI 分析

- 优化热门话题和关键词识别。部分模型不支持应用要求的固定输出格式时，应用会自动换一种兼容方式重试，减少“当前模型不可用”这类误报。
- 修复热门讨论话题可能重复显示的问题。现在同一个话题即使被模型分成多条结果，应用也会自动合并，话题列表和提及次数会更稳定。
- 优化群聊消息过滤。接龙、入群欢迎、群公告、签到提醒、“拍一拍”和微信版本不支持查看等系统类消息不会再进入 AI 分析、热门话题和关键词，减少无关内容干扰；“今天消息数”和“对话/群聊数”仍保留原始统计。

## 2.1.3

### 账号绑定

- 优化 macOS 微信多开识别。即使用户把多开的微信改成自定义名称或自定义包名，应用也能更准确地识别对应账号，减少绑定时找不到微信实例的情况。

### 看板体验

- 修复在每日清理时间后点击“重新分析”时，看板可能突然变空的问题。现在如果已进入新的业务日，应用会先重新读取当天消息，再继续生成分析结果。
- 优化“重新分析”过程中的看板刷新方式，分析还没完成时不会把当前页面切成空白，等待新结果生成后再更新展示。
- 修复点击“重新同步”后，部分昨天或更早还没完成的待办、待回复可能被清掉的问题。现在重新同步只刷新今天的数据，历史未完成事项会继续保留。

### AI 分析

- 优化 AI 对聊天记录中“自己发言”的理解。现在应用会更准确地区分哪些消息是用户自己发出的，减少已经回复过的问题仍被识别成“待我回复”的情况。

## 2.1.0

## 使用体验

- 精简主界面内部结构，保留原有使用方式，打开、切换和维护更稳定。
- 整理账号、看板、同步、AI 和设置相关能力，减少后续更新互相影响的概率。

## 平台绑定

- 重做平台账号绑定模块，账号列表、批量管理、平台入口和绑定窗口分工更清楚。
- 企微、飞书、钉钉采用统一的官方 CLI 绑定流程，操作步骤更一致。
- 微信本机绑定和微信官方 CLI 绑定分开处理，避免不同方式互相干扰。

## 消息同步

- 重构同步引擎，消息拉取、整理、保存和分析流程更清晰。
- 各平台通过统一入口接入，后续新增或调整平台时更不容易影响其他平台。

## AI 分析

- 拆分 AI 分析管线，提示词、分批、模型请求、摘要、关键词和待办处理各自独立。
- 后续调整提示词、切换模型或优化关键词时，风险更低。

## 数据与稳定性

- 梳理前后端数据约定，逐步减少同一份数据在两端重复手写带来的不一致。
- 补充核心逻辑测试基础，优先覆盖消息整理、平台命令、业务日窗口、AI 分批和看板数据。

## 平台管理

- 优化 CLI 检查更新的显示方式，状态和进度更清楚。
- 优化 CLI 下载和删除逻辑，减少无效残留。
- 平台管理页面新增批量管理功能，可一次处理多个账号。
- 平台账号支持拖拽排序，常用账号更方便调整位置。

## 消息同步

- 优化消息同步逻辑，支持多平台并发拉取消息，提高同步速度。
- 优化重新同步逻辑，重新同步时不会清空非今日的未完成待回复和待办。

## AI 分析

- 优化热门话题 AI 分析提示词，让话题总结更贴近日常表达。
- 优化热门话题提及次数统计逻辑，统计结果更准确。
- 优化重新分析逻辑，重新分析时不会清空非今日的未完成待回复和待办。

## 看板体验

- 看板卡片新增窗口大小自适应，不同窗口尺寸下显示更自然。
- 增加看板动画，切换和数据展示更顺滑。
- 优化界面排版，信息层级更清楚。

## 界面与安装包

- 优化多处界面文案，更符合中文使用习惯。
- 精简代码和打包内容，减小安装包体积。
- 优化运行效率，减少不必要的处理开销。
