# IM-Board Lite 更新日志

## 3.0.1

### 发布后质检修复

- Windows 桥接清理保留进程句柄并等待退出信号，避免 Job 计数提前归零时释放账号保护；主进程退出后清理后代，避免继承输出管道造成等待超时。
- CLI 归档路径在系统拆分路径之前拒绝反斜杠和驱动器分隔符，统一跨平台安全校验。
- macOS 内置钉钉 CLI 的实际执行测试限定在 macOS；其他主机继续验证资源完整性。

## 3.0.0


### 安全依赖更新

- 更新前端构建与测试工具：Vite 6.4.5、Vitest 4.1.12、source-map-js 1.2.2，修复本次 CI 检出的 npm 安全公告；保持现有前端架构。
- 更新 TLS 相关依赖 rustls 0.23.46、rustls-webpki 0.103.16、webpki-roots 1.0.10，以及 ZIP 9.1.0；修复本次 CI 检出的 9 项 Rust 依赖漏洞，保留现有安全解压路径检查。
- 主应用及原生进程模块统一升级 Tokio 1.53.3，修复新公布的 I/O 安全问题。


### 版本与展示

- 提供 Lite 版本保留企业微信、飞书、钉钉，使用独立应用标识、数据目录和凭据空间。
- Demo 仅包含桌面壳、网页预览、主题、展示交互和示例数据；账号、同步、AI 配置等操作使用内存示例，不初始化业务数据库、真实授权、外部 CLI 或模型进程。
- 完善浅色、深色、跟随系统及小窗口布局，统一提示条、长错误分页复制、弹窗和账号列表交互；窗口最小尺寸调整为 760×600。
- 修复未绑定账号的首次启动被误报为“本次没有账号同步成功”，完善零消息、未配置 AI、部分成功和真正失败的提示。

### 账号绑定与管理

- 绑定草稿由桌面端维护，按当前系统生成配置与缓存路径；关闭弹窗、异步结果返回和重复点击保存按绑定会话隔离。
- 保存前核验授权和账号身份，识别重复账号；账号备注、启停、排序及删除保持事务性和账号隔离。账号标识统一拒绝路径、非法字符和系统保留名称。
- 修复输入法确认候选词、按钮回车和窗口刚激活时的点击误触；Windows 完整版和 Lite 使用一致的输入法保护参数。
- 已校验的企业平台 CLI 共用应用级缓存；关闭草稿或删除单个账号不会卸载其他账号正在使用的可执行文件。

### 企业微信

- 更新并固定授权 CLI 1.3.4；修复新版搜索要求非空 `keywords` 时返回 40058 的问题。
- 保留授权可见通讯录的自动枚举、分页和逐联系人消息发现，辅以群聊读取；联系人搜索不再冒充完整通讯录列表。
- 修复发言人显示为账号标识的问题，按消息及已确认通讯录信息解析姓名，保持消息身份与多账号隔离。

### 飞书

- 更新并固定 CLI 1.0.98，适配当前授权、应用配置、用户身份和消息检索结构。
- 区分应用配置未完成、用户授权不完整、读取范围不足和网络失败；保留两阶段授权的明确说明。
- 从已有授权预检确认当前用户 OpenID，修复当天双方都有发言却未显示“与我聊最多”和“发言 Top10”的问题。

### 钉钉

- 更新内置 CLI 至 1.0.65-imboard.1，采用时间窗口消息读取和分页，不以先列联系人再逐个查找作为全局消息读取的前提。
- 修复登录回调、PowerShell 原生错误处理和账号隔离；Windows 使用每账号独立的 DPAPI 加密注册表空间，macOS 保留原生钥匙串方式。
- Windows 授权命令显示登录、消息权限授权、身份核验三个阶段；消息权限请求最多等待 180 秒，超时结束请求并保留登录凭据。保存配置遇到账号忙碌时立即提示，避免等待同一把锁长时间转圈。
- 修复未完成授权时直接显示原始 JSON 的问题，复用现有中文提示；权限不足、解密失败和普通文件错误保持独立分类。
- 修复组织用户 ID 与消息 OpenID 不一致导致排行榜为空：先查本人详情，缺少 OpenID 时仅按已确认的本人用户 ID 搜索并严格核对结果，不按姓名猜测身份。
- 保留消息原有单聊 / 群聊标记，重复同步可纠正此前的错误标记。

### 同步、统计与分析

- 自动同步周期由后端持久化和调度，窗口隐藏、重建或应用重启后继续生效；同步互斥、取消、重试和退出统一管理子进程生命周期。
- 账号分别记录最后尝试、最后成功与最近错误；失败不推进成功时间或游标，部分结果保留并可重试，连续失败按退避策略处理。
- 单账号重新同步与删除只清理该账号持有的数据和资源；按账号区分缓存、游标、会话及分析证据。
- “与我聊最多”继续要求当天同一账号的单聊双方都发过言；发言排行统一识别本人，防止将不同账号的一侧消息合并成双向聊天。
- 优化系统通知、成员变更、兼容性占位文本、签到、接龙和营销模板的过滤；保留正常业务讨论，改善消息类型、活跃分布、话题和关键词统计。
- 待回复、待办、话题和关键词使用稳定的消息证据与来源，历史未完成事项可跨日延续，单个分析阶段失败不丢弃已完成结果。

### AI 与本地模型

- 更新服务商默认接口地址，修复火山方舟错误继承本地回环地址；保留用户明确配置的自定义地址。
- 分批分析按完整上下文和请求预算控制，统一默认提示词、恢复默认及自定义提示词迁移；提升 JSON 解析、响应格式兼容和模型错误提示。
- API Key 存放于系统安全凭据服务，配置读取仅返回是否已设置；空输入保留已有密钥，支持显式清除。
- 本地模型由独立监督器管理回环端口、并发启动、就绪检查和退出回收；启用后核验模型身份与最小推理结果，按内存、CPU 和磁盘调整参数。
- 模型与运行时下载校验大小、哈希和安全解压；原子安装与有限版本保留避免半安装状态。Windows ARM64 的不支持能力会明确提示。

### 数据、安全与诊断

- 数据库采用版本化事务迁移，旧库升级前生成一致性备份；检测到较新数据库结构时拒绝旧程序写入。
- Lite 从旧目录导入时只读取支持平台的账号和业务数据，保留原库；不复制授权、AI 密钥、同步游标或运行时，导入账号默认停用并要求重新授权。
- 收紧前后端命令、参数和平台能力契约，后端按账号重新读取受信配置；启用 WebView 内容安全策略及 URL / 下载资源校验。
- 诊断仅保留结构化排错信息，对密钥、令牌和聊天正文脱敏；增加事件数量、保留天数和查询索引限制。

### 桌面与发行维护

- 修复 Windows 后台运行时主窗口无法恢复，完善单实例唤起、托盘显示、关闭窗口后台运行和退出清理。
- 拆分桥接执行、同步编排、平台绑定、进程所有权、统计和诊断模块，保留各系统的原生执行与资源管理路径。
- 发布版本、Edition、资源清单和依赖许可统一校验；内置运行时、第三方 CLI 和自维护副本通过文件哈希核验。
- 加入前端、Rust、脚本和版本边界回归测试；共享文件同步采用明确白名单、计划校验、暂存及失败恢复，平台专属文件显式适配。
- 发布构建映射编译机路径，移除开发诊断入口中的个人路径；Demo 不携带生产后端与运行时。
